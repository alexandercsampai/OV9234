# OV9234 IR sensor driver
still testing!! do not install unless you know what you're doing.  
The OV9234 IR sensor is in Lenovo Thinkpad X1 Carbon Gen 11 but currently has no support in linux  
this projects aims to create a driver so maybe in future we can get this IR sensor working fully and have possible facial recognition implemented for authentication.  

this project has been part built by AI.

how to install: 
`git clone https://github.com/alexandercsampai/OV9234.git`  
`cd OV9234`  
`chmod +x install.sh && ./install.sh`
